# Doodz Marketplace
1. Install Node.js (https://nodejs.org)
2. Open this folder in VS Code, then open the terminal (Ctrl + `)
3. Run: npm install
4. Run: npm run dev
5. Open the link shown (http://localhost:5173)
Login: any valid email + password with 6+ characters (demo only, no backend yet).

Build for production: npm run build (output goes to the dist folder)
